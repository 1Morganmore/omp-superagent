# omp-superagent 0.1.5

- **Codex subscription voice no longer needs Python.** The Rust Gateway handles
  WebRTC and Opus directly. Keep using the Codex CLI to sign in. A rejected
  subscription never falls back to paid API voice, and a spoken work request
  still requires written confirmation in Discord.
- **Large files and long sessions use less memory.** Lanes hash file evidence
  in chunks. When the head or a lane only needs a journal position, it asks for
  the last entry ID rather than loading the transcript.
- **Choose the head model and reasoning effort in your messenger.** `/model`
  and `/effort` offer choices from the running OMP session in Discord, Telegram
  and Slack. Selections are bound to the original card and session.
- **Long Discord replies are easier to read.** Replies that fit in up to five
  messages are sent in order, preserving code fences. Longer replies still use
  a text attachment.

## Install or upgrade

```sh
bun add --global --trust omp-superagent@0.1.5
omp-sa --help
```

Alternatively, run `npm install --global omp-superagent@0.1.5` with Bun 1.4.4
or later on `PATH`. The package includes native executables for macOS and Linux
(arm64 and x64). Installation does not restart a running Gateway.
