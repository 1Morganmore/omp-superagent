# omp-superagent 0.1.11

- **Idle HEADs can release memory.** After 30 minutes of verified inactivity, HEAD and its Host owner can exit while the Rust Gateway keeps receiving messages. The next request wakes the same session. Set `headIdleMs` to `0` to keep HEAD resident if first-response latency matters more.
- **Wake preserves the session and its service tier.** The Gateway checks the native profile, journal, model route and service tier before releasing queued messages. If the configuration changes during wake, restoring its exact bytes lets the same controller continue without resending the request.
- **Messenger recovery preserves order.** Discord and Slack recover history only through the end of each connection gap. Slack edits keep their original topic, and a replacement HEAD continues unfinished reads without replaying completed effects.
- **HEAD and lanes communicate directly.** Direct lane reports and follow-ups replace the board tools. HEAD can answer before a background job finishes and retain the job's result for that request. Messenger commands with space-separated arguments now preserve their arguments.
- **Choose HEAD fast mode from the messenger.** The `/fast` picker shows the current mode; changing it requires confirmation. The SDK and CI baseline are now stock OMP 19.2.1.

## Install or upgrade

```sh
bun add --global --trust omp-superagent@0.1.11
omp-sa --help
```

Alternatively, use `npm install --global omp-superagent@0.1.11` with Bun 1.4.4 or later on `PATH`. Install OMP separately. Installing does not restart a running Gateway; stop and start it normally so the Gateway and HEAD use the same installation.
