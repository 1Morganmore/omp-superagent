# omp-superagent 0.1.0

First source release: one messenger-facing OMP head, with independent work lanes.

- Discord, Telegram, and Slack adapters with durable intake and owner-scoped routing.
- Native OMP sessions, approvals, model selection, and recovery through public APIs.
- Managed extensions and reconnectable local transport, without OMP core patches.
- A shared informational board and managed omp-ulw integration.
- Interactive setup, the `omp-sa` CLI, and optional one-shot macOS login startup.
- MIT-licensed project code, with separate third-party notices.

## Install

Download `omp-superagent-0.1.0.tar.gz` and its `.sha256` file from this release.
Verify the checksum, extract the archive, and follow the included README.
This is a Bun source distribution, not a standalone executable or npm package.
It requires Git, Bun 1.4.4 or later, a separately installed OMP >=18.20.2 and <19,
and Unix sockets. OMP 18.20.2 is the tested baseline. Installation checks OMP and
prepares published dependencies and the managed ULW integration; it does not build,
patch, or replace OMP. No bot starts until an explicit `start`.
Native TUI/herdr attachment to managed RPC sessions is not supported.

## Verification scope

The release workflow gates publication on type checking and local regression tests,
including offline native Host/Gateway and setup PTY fixtures, on Linux and macOS.
The macOS launchd case is platform-specific. These checks do not verify live messenger
accounts, paid model providers, herdr, or a real login/reboot. Windows is not supported.
ULW follows its upstream default branch during preparation and later managed updates;
the CI log records the exact revision used by that run.
