# omp-superagent 0.1.6

**Upgrade requirement:** Managed heads and lanes now require the native OMP memory backend `mnemopi` in their effective profile and workspace. Run `omp-sa doctor --config ./config.local.json` before restarting. Installation does not change global OMP settings or restart a running Gateway.

- **Topic sessions and recall.** Ordinary owner work stays in its topic session; use `/head` for global coordination. To continue earlier work, describe it: the controller checks recall candidates against authorized session journals instead of copying another topic’s transcript or approvals.
- **Discord thread continuity.** Follow-ups stay in the current work thread unless the owner explicitly asks for a sibling. If a delivered workspace clarification goes unanswered for five minutes, work can continue with the scoped fallback. A timely reply or stop takes precedence.
- **Restricted rooms and result files.** Operators can allow specific room members to submit requests, ask questions, or work in a scoped checkout without access to owner sessions. On an owner route, use a leading `attach: path/to/result.pdf` line to authorize delivery of that specific file to the original topic.
- **Head restart and rotation.** An owner can request `/restart` while the head is busy. It checkpoints head work and restores the same native session, model, effort and memory without restarting independent lanes. Automatic rotation is separate: an eligible idle head with high context usage starts a fresh journal without replaying old work.
- **Verified superkit loading.** A new head or lane cannot become ready unless stock OMP reports every selected `omp-superkit` module active. `omp-sa status` distinguishes the attached head’s verified `gateway.head.loadedSuperkitPath` from `gateway.ulw.packagePath`, the package selected for the next Host. Verified updates do not hot-reload running sessions.
- **OMP 19.1 compatibility.** The integration distinguishes automatic reasoning effort from its effective level and handles unsupported HTML forms without accepting them as owner decisions.

## Install or upgrade

```sh
bun add --global --trust omp-superagent@0.1.6
omp-sa --help
```

Alternatively, use `npm install --global omp-superagent@0.1.6` with Bun 1.4.4 or later on `PATH`. The package includes native executables for macOS and Linux (arm64 and x64); running a Host still requires a separately installed OMP.
