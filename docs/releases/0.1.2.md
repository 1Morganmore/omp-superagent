# omp-superagent 0.1.2

- HEAD now receives only its core operating skill on each model turn. It reads
  detailed routing, model selection, and supervision from the installed package
  when needed. The routing skill distinguishes independent lane outcomes from
  subtasks of one deliverable, and favors separate worktrees for independent
  edits. A single original input can still create at most one new lane.
- Add Discord forum tags and managed thread controls, original-message replies
  and channel context, explicit GitHub PR tracking, and native owner decisions
  that HEAD can resolve for routine, reversible choices.
- Add owner-only Discord voice, off by default, with a Codex subscription or a
  separately billed OpenAI API option. See the [voice setup guide](https://github.com/dbc-hbin/omp-superagent/blob/v0.1.2/docs/discord-voice.md).
- Support owner-requested HEAD model changes and refresh managed presets when
  their source OMP model roles change.

## Install or upgrade

The original GitHub `v0.1.2` downloads are unchanged. They require Git,
Bun >= 1.4.4, a separately installed **OMP >= 19.0.0 and < 20.0.0**, and local
Unix sockets. Before moving from OMP 18 to 19, check any background services
still owned by the old Host; the new daemon does not take them over.

npm registry version `0.1.2` is not available. Download
`omp-superagent-0.1.2.tgz` and its checksum from the
[GitHub release](https://github.com/dbc-hbin/omp-superagent/releases/tag/v0.1.2).
After verifying the checksum, install the tarball:

```sh
bun add --global --trust ./omp-superagent-0.1.2.tgz
omp-sa --help
```

Alternatively, with Bun on `PATH`:

```sh
npm install --global ./omp-superagent-0.1.2.tgz
```

Keep lifecycle scripts enabled: they check the installed OMP and prepare the
managed ULW integration. Installing does not start a bot or replace a running
Host. See the [operations guide](https://github.com/dbc-hbin/omp-superagent/blob/v0.1.2/docs/OPERATIONS.md)
before starting or restarting.
The GitHub `.tar.gz` is the source archive; `.tgz` is the npm package.

The tag workflow verifies the SDK-matched stock OMP 19.0.0 on Linux and macOS
before GitHub publication. Offline tests do not verify real messenger accounts,
live voice/provider behavior, login startup, or native TUI attachment.

## Compatibility changes after the `v0.1.2` tag

The current source can be installed without OMP on `PATH`. At runtime it checks
the configured OMP executable's capabilities instead of enforcing a version
range. Stock OMP **18.20.3, 18.22.2, and 19.0.0** each passed the 1,228-test
regression suite on macOS arm64. These changes are not in the original GitHub
downloads.
