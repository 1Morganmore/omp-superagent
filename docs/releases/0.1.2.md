# omp-superagent 0.1.2

- Remove the OMP version check during installation. At runtime Superagent checks
  the configured OMP executable's capabilities rather than enforcing a version
  range. Stock OMP 18 and 19 both support session resume and managed service
  ownership; the SDK remains pinned to 19.0.0.
- HEAD now receives only its core operating skill on each model turn. It reads
  detailed routing, model selection, and supervision from the installed package
  when needed. The routing skill distinguishes independent lane outcomes from
  subtasks of one deliverable, and favors separate worktrees for independent
  edits. A single original input can still create at most one new lane.
- Add Discord forum tags and managed thread controls, original-message replies
  and channel context, explicit GitHub PR tracking, and native owner decisions
  that HEAD can resolve for routine, reversible choices.
- Add owner-only Discord voice, off by default, with a Codex subscription or a
  separately billed OpenAI API option. See the [voice setup guide](https://github.com/dbc-hbin/omp-superagent/blob/v0.1.2/docs/discord-voice.md).
- Support owner-requested HEAD model changes and refresh managed presets when
  their source OMP model roles change.

## Install or upgrade

Installation requires Git and Bun >= 1.4.4, but does not require OMP on `PATH`.
Running a Host requires a compatible stock OMP executable and local Unix sockets.
Before switching a Host from OMP 18 to 19, check its background services;
the OMP 19 daemon does not take over services from the OMP 18 broker.

Install `omp-superagent@0.1.2` from npm, or download the verified
`omp-superagent-0.1.2.tgz` from this GitHub release if npm publication is pending.

```sh
bun add --global --trust omp-superagent@0.1.2
omp-sa --help
```

Alternatively, with Bun on `PATH`:

```sh
npm install --global omp-superagent@0.1.2
```

Keep lifecycle scripts enabled to prepare the managed ULW integration.
Installing does not start a bot or replace a running Host. See the
[operations guide](https://github.com/dbc-hbin/omp-superagent/blob/v0.1.2/docs/OPERATIONS.md)
before starting or restarting.
The GitHub `.tar.gz` is the source archive; `.tgz` is the npm package. For a
downloaded `.tgz`, verify its SHA-256 and use the file path in the install command.

Stock OMP **18.20.3, 18.22.2, and 19.0.0** each passed 1,228 regression tests
on macOS arm64. Release CI additionally checks Linux and macOS with stock
binaries before publishing. Offline tests do not verify real messenger
accounts, live voice/provider behavior, login startup, or native TUI attachment.
The original OMP-19-only GitHub build was made from `7d18ab563cd1`; the
replacement is built from the commit referenced by the updated `v0.1.2` tag.
