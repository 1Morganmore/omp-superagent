# omp-superagent 0.1.1

First npm release, based on the work through `a3139fd`.

- Install the `omp-sa` CLI from npm with Bun or npm, without cloning the repository.
- Include runtime sources, managed role skills, ULW preparation, configuration examples,
  documentation, artwork, and third-party notices in the npm package.
- Publish source and npm tarballs with SHA-256 checksums on GitHub.
- Include native OMP session discovery, bounded Discord Markdown table rendering,
  and explicit native jevify workflow selection added since 0.1.0.

## Install

Requires Git, Bun >=1.4.4, a separately installed OMP >=18.20.2 and <19, and Unix sockets.
Windows and same-process native TUI/herdr attachment are not supported.

```sh
bun add --global --trust omp-superagent@0.1.1
omp-sa --help
omp-sa setup --config ./config.local.json
omp-sa doctor --config ./config.local.json
```

Alternatively, with Bun on PATH:

```sh
npm install --global omp-superagent@0.1.1
```

Bun's `--trust` permits the installed-OMP check and managed ULW preparation scripts.
Do not disable lifecycle scripts. Installation does not patch or build OMP, start
a bot, or activate a model session. Run `omp-sa start --config ./config.local.json`
only when ready to connect every configured messenger.

The GitHub `.tar.gz` is a source archive: extract it and run
`bun install --frozen-lockfile` followed by `bun link`. The `.tgz` is the npm package.

## Verification scope

The tag workflow gates GitHub publication on type checking and the offline native,
Gateway, and setup PTY regression suite on Linux and macOS. Local package installation
and CLI checks cover distribution, not live messenger accounts, paid model providers,
herdr, or a real login/reboot. The OMP SDK baseline remains 18.20.2; managed ULW follows
its upstream default branch and records its exact prepared revision.
